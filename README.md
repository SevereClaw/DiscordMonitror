# Music → Discord

Показывает в статусе Discord, что ты слушаешь: VLC, MP3 Плеер, браузер (YouTube) и другие
плееры Windows. Обложки (в том числе из самого файла), текст песни строчками,
две карточки «Слушает» + «Смотрит», кнопки, свои шаблоны.

## Скачать

**[Releases → последняя сборка → Music-Discord.exe](../../releases/latest)**

Скачай и запусти — Python не нужен. Новая сборка появляется сама после каждого изменения
в репозитории (вкладка **Actions**).

## Как подключить к Discord

Делается один раз, занимает пару минут. При первом запуске программа сама открывает окно
**«Подключение к Discord»** и ведёт по шагам; позже его можно открыть кнопкой
**«Подключить по шагам»** на вкладке «Главное».

**Что нужно заранее**

- Windows 10 или 11.
- Программа Discord на этом же компьютере, открытая и с выполненным входом.
  Discord во вкладке браузера не подходит — нужна программа с [discord.com/download](https://discord.com/download).
- Если Discord у тебя работает только через VPN — включи его.

**Шаг 0. Запусти Music-Discord.exe**

Скачай `Music-Discord.exe` из [последней сборки](../../releases/latest) и запусти.
Windows может показать синее окно «Система Windows защитила ваш компьютер» — нажми
**«Подробнее» → «Выполнить в любом случае»** (так бывает со всеми программами без платной подписи).

**Шаг 1. Создай «приложение» в Discord**

Discord показывает статус только от имени «приложения». Программировать ничего не надо — это просто название.

1. В окне подключения нажми **«Открыть сайт Discord для разработчиков»**
   (или сам открой [discord.com/developers/applications](https://discord.com/developers/applications)).
2. Войди в свой аккаунт Discord, если сайт попросит.
3. Справа вверху нажми синюю кнопку **New Application**.
4. Впиши название. Его увидят друзья: «Слушает *название*». Например, `Музыка`.
5. Поставь галочку под названием и нажми **Create**.

**Шаг 2. Скопируй Application ID**

1. После Create откроется страница **General Information**.
2. Найди надпись **APPLICATION ID** — под ней длинное число из 17–20 цифр.
3. Нажми под ним кнопку **Copy**.
4. Вернись в Music → Discord. Программа сама замечает скопированный ID и подставляет его.
   Если не подставила — нажми **«Вставить»**.

Не перепутай: **Public Key** (строка из букв и цифр ниже), **Client Secret** и **токен бота** не подходят.
Программа узнаёт их и скажет, что вставлено не то.

**Шаг 3. Проверь**

Нажми **«Проверить и подключить»**. Программа постучится в Discord и ответит:

- **«Готово! Discord принял подключение»** — всё, окно можно закрыть.
- или напишет, что именно не так и что делать (см. таблицу ниже).

**Шаг 4. Включи музыку**

Включи трек в MP3 Плеере, VLC, браузере или другом плеере. Секунд через 10 он появится
в твоём профиле Discord (нажми на свою аватарку слева внизу). Задержка нужна, чтобы в статус
не попадали треки, которые ты пролистываешь; меняется на вкладке «Главное».

Дальше программа живёт в трее возле часов. Чтобы она запускалась сама — включи
«Запускать вместе с Windows» на вкладке «Главное».

### Если не получается

| Что видишь | Почему | Что сделать |
|---|---|---|
| «Discord не запущен» | Программа Discord закрыта, или Discord открыт в браузере | Открой программу Discord, дождись загрузки, нажми «Проверить» ещё раз |
| «Discord ещё загружается» | Discord открыт, но не отвечает | Подожди полминуты. Не помогло — значок Discord возле часов → правый клик → **Quit Discord**, открой заново |
| «Discord запущен от имени администратора» | Discord запущен с правами администратора, а Music → Discord — без них | Закрой Discord совсем (Quit Discord) и открой обычным двойным кликом. В свойствах ярлыка не должно стоять «Запускать от имени администратора» |
| «Discord не знает такой Application ID» | Вставлено не то число (например, твой ID пользователя) или приложение удалено | На сайте открой своё приложение и нажми **Copy** под APPLICATION ID |
| «Это Public Key / токен бота / Client Secret» | Скопирована соседняя строка | Нужна строка **APPLICATION ID** на странице General Information: в ней только цифры |
| Сайт Discord не открывается | Discord недоступен без VPN | Включи VPN и открой сайт снова |
| Проверка прошла, а статуса нет | Музыка играет меньше 10 секунд; включена «Невидимка»; трек в чёрном списке | Подожди 10 секунд; посмотри плашку в окне программы — там написано, что происходит |
| У меня статус есть, а друзья не видят | В Discord выключен показ активности, или стоит статус «Невидимый» | Discord → Настройки → «Конфиденциальность активности» → включи показ своей активности другим. Поставь статус «В сети» |
| Вместо обложки серый квадрат с «?» | Discord не успел загрузить картинку | Подожди один-два трека; свою картинку можно задать кнопкой «🖼 Обложка» |

Две дополнительные карточки — «Смотрит» (видео) и «VPN из NekoBoxP3R» — подключаются так же,
но каждой нужно **своё** приложение: повтори шаги 1–2 с другим названием и вставь ID
в поле на вкладке «Источники».

**Обновляется сама:** раз в 6 часов проверяет GitHub, скачивает новую сборку, подменяет
exe и перезапускается (в трее — уведомление). В меню трея: «Проверить обновления»
и «Обновляться автоматически». Настройки не пропадают. После обновления программа
показывает, что изменилось (и в трее — «Что нового»).

**Своя обложка.** Если iTunes подобрал не ту картинку — кнопка «🖼 Обложка»: вставь
ссылку на картинку (или имя картинки из Art Assets своего приложения, или выбери файл)
и выбери «для всего альбома» или «только для этого трека». Запоминается навсегда.

**VPN из NekoBoxP3R.** Третья карточка «Играет в NekoBoxP3R»: флаг и страна VPN, сервер и режим,
сколько времени подключено, клик — на [NekoBoxP3R](https://github.com/SevereClaw/NekoBoxP3R) на GitHub.
Настройки → «VPN из NekoBoxP3R»: создай приложение «NekoBoxP3R» на discord.com/developers и вставь его ID.

## Собрать у себя

`build.bat` (нужен Python 3.10+) — готовый `Music-Discord.exe` появится рядом.
