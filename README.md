# Music → Discord

Показывает в статусе Discord, что ты слушаешь: VLC, MP3 Плеер, браузер (YouTube) и другие
плееры Windows. Обложки (в том числе из самого файла), текст песни строчками,
две карточки «Слушает» + «Смотрит», кнопки, свои шаблоны.

## Скачать

**[Releases → последняя сборка → Music-Discord.exe](../../releases/latest)**

Скачай и запусти — Python не нужен. Новая сборка появляется сама после каждого изменения
в репозитории (вкладка **Actions**). Обновиться: закрой программу (трей → «Выход»)
и замени exe — настройки хранятся отдельно и не пропадут.

## Собрать у себя

`build.bat` (нужен Python 3.10+) — готовый `Music-Discord.exe` появится рядом.
