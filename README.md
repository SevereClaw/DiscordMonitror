# Music → Discord

Показывает в статусе Discord, что ты слушаешь: VLC, MP3 Плеер, браузер (YouTube) и другие
плееры Windows. Обложки (в том числе из самого файла), текст песни строчками,
две карточки «Слушает» + «Смотрит», кнопки, свои шаблоны.

## Скачать

**[Releases → последняя сборка → Music-Discord.exe](../../releases/latest)**

Скачай и запусти — Python не нужен. Новая сборка появляется сама после каждого изменения
в репозитории (вкладка **Actions**).

**Обновляется сама:** раз в 6 часов проверяет GitHub, скачивает новую сборку, подменяет
exe и перезапускается (в трее — уведомление). В меню трея: «Проверить обновления»
и «Обновляться автоматически». Настройки не пропадают. После обновления программа
показывает, что изменилось (и в трее — «Что нового»).

**Своя обложка.** Если iTunes подобрал не ту картинку — кнопка «🖼 Обложка»: вставь
ссылку на картинку (или имя картинки из Art Assets своего приложения, или выбери файл)
и выбери «для всего альбома» или «только для этого трека». Запоминается навсегда.

**VPN из NekoBoxP3R.** Третья карточка «Играет в NekoBoxP3R»: флаг и страна VPN, сервер и режим,
сколько времени подключено, клик — на [NekoBoxP3R](https://github.com/SevereClaw/NekoBoxP3R) на GitHub.
Настройки → «VPN из NekoBoxP3R»: создай приложение «NekoBoxP3R» на discord.com/developers и вставь его ID.

## Собрать у себя

`build.bat` (нужен Python 3.10+) — готовый `Music-Discord.exe` появится рядом.
